# Schema — the rules of this map

The closed set of card types, the frontmatter they carry, and how they are named. When a card
and this file disagree, fix one of them the same day.

## Card types

| `type:` | Lives at | Carries |
|---|---|---|
| object | `objects/<cluster>/<slug>.md` | one noun: a Go type, a data file or table, or a package that owns one |
| process | `processes/<slug>.md` | one movement that really runs: Input → Movement → Output, numbered steps |

Effects (`effects/CONTEXT.md`) and indexes (`objects/_index.md`, `processes/_index.md`) are
catalogs, not cards.

## Clusters (objects)

| Cluster | Holds |
|---|---|
| `sources` | what the user connects: source definitions and each source type |
| `valuation` | what it is worth: prices, the priced snapshot, value history |
| `views` | how the user slices and watches it: portfolios, alert rules |
| `ledger` | money over time: activity, cost basis, tax lots, tax reports, CSV export |
| `storage` | where state lives: database, YAML stores, config, secret key, backup files |
| `web` | the UI: server and routes, page models, templ components, static assets, demo fixtures |

## Frontmatter

```yaml
type: object            # or process
cluster: sources        # objects only
universe: live          # live | leftover | ghost (see ../CONTEXT.md)
status: verified        # stub | verified | stale
verified: 2026-10-19 @ e280a97   # date @ short commit; required when status is verified
entity: internal/sources/registry.go   # objects: the file that owns the noun
consumes: [source-def]  # processes: object slugs read
produces: [snapshot]    # processes: object slugs written
```

`status: verified` needs the date, the commit and `path:line` citations in the body. A card
whose citations no longer match the code is `stale` until someone re-verifies it.

## Naming

- Slugs are kebab-case and unique across all clusters, so a bare slug (`price`) names one card.
- Links between cards are relative markdown links: `[price](../valuation/price.md)`.
- Cite source as `path:line` from the repo root (`internal/prices/prices.go:42`).
- `objects/_index.md`, `processes/_index.md` and the `AGENTS.md` / `routing.md` twins are
  generated by `task map`. Never edit them by hand.
