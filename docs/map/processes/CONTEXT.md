# processes — one card per movement that really runs

**Reads:** the code path each card cites, and the object cards in its `consumes`/`produces`.
**Writes:** `processes/<slug>.md`, copied from [../_templates/process.md](../_templates/process.md).
**Human check:** every step cites `path:line`, and the steps run in the order written.

Only movements the app actually performs (a scheduled refresh, a sync, a request) get a card.
No aspirational flows. The list is [_index.md](_index.md), generated by `task map`.
