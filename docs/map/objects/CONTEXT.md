# objects — one card per noun

**Reads:** the source file each card cites. **Writes:** `objects/<cluster>/<slug>.md`, copied
from [../_templates/object.md](../_templates/object.md). **Human check:** the *If you change
this* section names real first-order effects, and every claim has a `path:line` citation.

Clusters follow how an editor asks, not the folder layout (see [../_meta/schema.md](../_meta/schema.md)):
sources · valuation · views · ledger · storage · web.

The list of cards is [_index.md](_index.md), generated by `task map`. Open one card, not a cluster.

Add a card when a new durable noun appears (a type other packages use, a data file, a table).
Re-verify a card (`status`, `verified: date @ commit`) whenever you change what it cites;
if you can't, set `status: stale`.
