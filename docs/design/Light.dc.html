Light mode

Same token names, same roles. Surfaces flip to white cards on a cool grey ground, and the accent and semantic hues get darker so text in them passes 4.5:1 on white. Cards gain a hairline shadow because borders alone read too faint on light grounds.

Switching themes

Follow the system Default to the OS setting, with a manual override in Settings: System, Light, Dark.
Swap tokens, not components Components only reference token names. Every example screen here takes a theme switch in its Tweaks panel.
Charts keep their order Allocation colors stay in the same sequence in both modes, so BTC is always the first, warm segment.
