Vault design system · v0.1

Foundations

A quiet, dense interface for tracking holdings across exchanges and self-custody wallets. Numbers come first: every figure is set in a tabular mono, every change carries a sign and an arrow, and color never carries meaning alone.

01 Numbers first Balances are the loudest thing on screen. Chrome stays out of the way.
02 Source is visible Every holding shows where it lives: exchange, hot wallet or hardware.
03 Read-only by default Viewing never risks funds. Sending is a separate, deliberate step.
